Bienvenue

Choisissez votre profil, ou créez-en un. Votre progression est enregistrée dans le navigateur de cet ordinateur. Le code à 4 chiffres évite qu'un autre apprenant utilise votre profil sur un poste partagé.

Conseils de posture
  • Dos droit, pieds à plat, écran à hauteur des yeux, à environ 60 cm.
  • Poignets souples, sans les poser sur le bord du clavier pendant la frappe.
  • Index gauche sur F, index droit sur J : ces deux touches ont un petit relief.
  • Les autres doigts : Q S D à gauche, K L M à droite ; les pouces sur la barre d'espace.
  • Faites une pause de quelques minutes toutes les 20 minutes.
  • Utilisez un ordinateur avec un vrai clavier : le tuteur ne fonctionne pas sur téléphone.

Éditeur simulé : les raccourcis agissent dans ce cadre, pas dans le navigateur. Si une fenêtre du navigateur s'ouvre malgré tout, fermez-la et continuez.
